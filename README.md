# Запуск

```bash
./run_docker.sh        # проверка ROS 2 на Ubuntu 24.04/Jazzy
./run_gazebo.sh        # Gazebo + Betaflight SITL
./run_raspberry_pi.sh  # Эмулятор архитектуры ARM (виртуальная машина качается). QEMU ARM64 + ROS 2 + MSP-эмулятор
```
Тоже самое что minimal, но дополнительно я прогнал у себя через симуляторы.
Каждый скрипт это отдельная проверка.
